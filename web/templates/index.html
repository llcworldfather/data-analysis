    常见问题
    
    
    

      
    
        
    上传后提示「缺少必要列」？
    
        
    
          系统支持两套列名，满足其中之一即可：
    
          · SAP 导出格式：ZMATNR IDNRK MENGE ZDJ
    
          · 标准命名格式：产品编码 组件编码 MENGE 组件单价
    
          若仍报错，请检查列名是否有多余空格或全角字符。
        
    
      
    

      
    
        
    为什么 MENGE 为 0 的行被过滤掉了？
    
        
    分析脚本会自动过滤 MENGE ≤ 0 的行，因为用量为零的组件不参与成本计算。如有异议请检查源数据中的零值行。
